# ArduinoProjects

**ArduinoProjects** is a collection of small, focused Arduino-based programs demonstrating various hardware and software concepts.  
Each project is contained in its own folder and written to be clear, modular, and easy to modify.  
This repository is aimed at learning, experimenting, and building practical tools using Arduino-compatible boards.

---

## Overview

This repository contains multiple standalone examples covering topics such as:

- Basic microcontroller programming
- WiFi networking (ESP32)
- Bluetooth communication
- Serial communication and interactive menus
- Utility functions and diagnostic tools

More projects will be added over time as the collection expands.

---

## Microcontroller Compatibility

Currently tested and working on:

- **Arduino Nano ESP32**

Additional boards may be supported in the future as the repository grows.

---

## Technology Stack

- **Language:** Pure C/C++ (Arduino Core)
- **Platform:** Arduino IDE 2.x
- **Libraries:** Only standard Arduino and official ESP32 libraries unless otherwise noted
